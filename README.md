# Henry Kirby – Portfolio Website

My personal portfolio website, built as part of my first year of the BSc in Creative Computing at South East Technological University (SETU).

**Live site:** https://kirbus77.github.io/portfolio/

## About the project

A single-page, responsive website that introduces me, my skills and my experience. The hero section has an animated background made with p5.js, which links to what I'm learning in my Creative Programming module.

## Features

- Responsive layout that works on mobile, tablet and desktop
- Mobile navigation menu that opens and closes with JavaScript
- Animated p5.js background where dots glow when the mouse is near
- Smooth scrolling between sections
- Contact links to email, LinkedIn and GitHub

## Built with

- HTML5
- CSS3 (Flexbox, media queries, custom properties)
- JavaScript
- [p5.js](https://p5js.org/)

## How to run it

1. Clone the repository:
   ```
   git clone https://github.com/Kirbus77/portfolio.git
   ```
2. Open `index.html` in your web browser.

No installation is needed.

## What I learned

- Structuring a web page with semantic HTML
- Making a layout responsive with Flexbox and media queries
- Using JavaScript to respond to user clicks
- Adding a p5.js sketch to a normal web page
